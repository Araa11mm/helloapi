\# helloapi — практическое занятие №1



Минимальный HTTP-сервер на Go с двумя маршрутами:

\- `/hello` — текстовое приветствие;

\- `/user` — данные пользователя в формате JSON со случайным UUID.



\## Требования



\- Go 1.27 или новее.

\- Git для работы с репозиторием.



Работа выполнена на Windows с Go 1.27.2 и Git 2.51.2.



\## Структура проекта



```text

helloapi/

├── cmd/

│   └── server/

│       └── main.go

├── go.mod

├── go.sum

└── README.md

```



\## Зависимости



Используется библиотека `github.com/google/uuid` версии v1.6.0.



В `go.mod` указаны модуль и версии зависимостей.

В `go.sum` хранятся контрольные суммы для проверки зависимостей.



\## Запуск



Откройте PowerShell в корневой папке проекта и выполните:



```powershell

go mod download

go run ./cmd/server

```



Сервер доступен по адресу `http://localhost:8080`.



Для остановки нажмите Ctrl+C в окне сервера.



\## Проверка



При работающем сервере откройте другое окно PowerShell:



```powershell

curl.exe -i http://localhost:8080/hello

curl.exe -i http://localhost:8080/user

```



Оба маршрута возвращают статус `200 OK`.



Ответ `/hello`:



```text

Hello, world!

```



Ответ `/user` имеет заголовок `Content-Type: application/json`:



```json

{"id":"a14a9328-d053-4e16-8cf3-794c9a0c0682","name":"Gopher"}

```



UUID генерируется заново при каждом запросе.



Маршруты также можно открыть в браузере:

\- http://localhost:8080/hello

\- http://localhost:8080/user



\## Сборка и запуск EXE



Остановите ранее запущенный сервер, затем выполните:



```powershell

go build -o helloapi.exe ./cmd/server

.\\helloapi.exe

```

\## Настройка порта



Порт `8080` задан в файле `cmd/server/main.go` строкой:



```go

addr := ":8080"

```



Для смены порта измените эту строку и заново запустите программу.

Если используете EXE, перед запуском пересоберите его.
